## 账单名称标签约定

| 标签 | 含义 |
|---|---|
| `[AA·N人]` | N 人均摊（无独占） |
| `[独占]` | 个人消费=账单全额 |
| `[解耦垫付]` / `(X垫付)` | 付款人 ≠ 独占消费者 |
| `[混合]` | 同一单既有均摊又有独占 |
| `[付款人不参与]` | payer 不在 participants |
| `[计算器]` | 含 `amount_expression` |
| `[CNY]` / `[THB]` / `[USD]` | 账单币种提示 |
| `[我创建·可改删]` / `[非我创建·不可改]` | 编辑权限 |
| `[结算记录]` / `[CNY还款]` | 已结算记录备注 |

泰国账本内既有命名（如 `7.25按摩Ju+Canyina独占(像汤圆付)`）同样遵循「独占 / 垫付 / N人」可读约定。
